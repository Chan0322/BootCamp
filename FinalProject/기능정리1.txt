- 회원가입
    - DB의 컬럼을 통해 사용자, 판매자, 관리자 구분(Consumer, Sellor, Admin)
    - 판매자 : 쇼핑몰 사이트 판매자 회원가입
        - 아이디, 비밀번호, 생년월일, 전화번호, 주소, 이메일, 닉네임
        - 아이디 중복 체크 : 프론트 → 백엔드 → DB와 비교
            - 비동기식으로 화면 바뀌지 않고 중복 체크
        - 비밀번호 체크
            - 글자 수, 특수 문자 여부…..(ex. 8자리 이상 특수 문자 포함)
            - 첫번째 입력한 비밀번호와 두번째 입력한 비밀번호가 같은지 체크
        - DB 저장시 비밀번호 암호화 필요
        - 처음 가입 시, DB의 입점 상태 컬럼 N으로 설정.
            - 관리자 승인으로 입점 상태 컬럼 Y로 변경 시 상품 등록 및 관리 가능
        - 핸드폰 번호 인증 문자 전송을 통한 회원 인증 후 성공 시 회원가입 진행 가능
            - 인증번호는 서버에서 랜덤으로 생성한 번호를 redis에 저장하여 사용자에게 문자 전송

- 장바구니
    - JWT에 저장된 로그인된 회원의 정보를 가져와서 장바구니 DB에서 해당 회원의 장바구니를 가져온다.

    - 일반 구매 장바구니
        - 주문하기 버튼 표시
        - 장바구니 목록에 체크 박스를 두고 체크된 항목만 주문.
    - 선물용 장바구니
        - 선물하기 버튼 표시

        - 체크 박스 1개만 선택 시 바로 선물

        - 선택 삭제 기능

        - 제품별 바로 구매 버튼 생성- 단 건 구매
        - 장바구니 제품 수량 및 옵션 변경

            - 배송지 대표 이름 지정(예. 집, 회사)

            - 친구 위시리스트

- 선물&주문&결제하기
    
    제품 1개 체크 시 자동으로 단건 선물하기
    
    제품 2개 이상 체크하고 선물 클릭하면 여러개 중 선택하는 선물
    
    - 멘토링 후 결정할 부분
        
        2개 이상 체크하고 선물 클릭하면 여러개 중 선택하게 할 건지 다 선물할지 선택하는 팝업
        
        같은 선물을 여러명에게 선물할 경우에는 친구 목록에서 친구 선택 시 다중 선택
        
    - 선물(1개)
        - 선물할 친구 선택
        - 선물 결제
        - 결제 후 선물할 친구에게 링크가 전송되고 이 링크를 클릭 시 친구가 주소 작성할 수 있게 진행
    - 선물(수신자가 여러개 중 선택)
        - 선물할 친구 선택
        - 친구에게 선물 리스트를 링크로 전송하고 링크를 통해 1개의 선물을 선택 및 주소 입력.
        - 선택한 선물에 대한 결제 링크를 사용자에게 전송.
    - 일반 구매
        - 수신자 정보 입력
            - 배송지 목록에서 배송지 선택
    - 공통
        - 주문할 상품 상세 내역
            - 상품 갯수, 선택한 옵션 및 가격 표시
        - 결제 진행(간편 결제)
            - 포트원 API 사용.
        - 주문이 완료가 되면 카카오톡으로 알림 전송.
            - 카톡 나에게 보내기 API
        - 주문 완료 시 상품 재고 -1
        - 선물 공통 기능
            - 메시지 카드 작성하기
                - 카드 꾸미기
                - 사진 첨부
                - 원하는 문구 작성
                - 수신자가 선물 링크 접속 시 해당 메시지 카드 띄우기
